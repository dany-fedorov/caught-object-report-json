Class CorjRedactor

Applies one policy, reporting a throwing callback exactly once per value and failing closed: a policy that cannot decide yields the replacement rather than the value it was asked about.

Private failing

failing: boolean = false

Set while a policy failure is being reported. Reporting a failure runs the default onError, which redacts the line it prints; this stops the same throwing policy from being consulted again to describe its own failure.
