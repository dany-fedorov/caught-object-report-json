  • restoreExpectedValues: (<T>(report) => T)
      • <T>(report): T

      • Fill in the fields a report omitted as expected values, so every node has instanceof_error, typeof, as_json, as_string_format and as_json_format, the root has children_sources, and as_string, constructor_name and message are parsed back out of the first stack line when they were omitted as well.

        The result is a complete report, so v and $schema are relabelled to the -full version. v and $schema themselves are not added when absent, since a missing one means metadata was disabled.
